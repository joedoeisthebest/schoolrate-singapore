# SchoolRate Singapore

A Next.js project for SchoolRate Singapore.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit it.

This project uses `next/font` to optimize and load Geist, a font family for V​​ercel.
